# Dolmuş Boş Koltuk Protokolü

> Resmi olmayan resmi daire. Eskisehir 4. Agir Ceza'nin otobüs duragindaki yan odasi.
> Patates yasaktir. Simit serbesttir ama sayilmaz.

Bu depo, dolmusta gozle gorulen bos koltugun neden senin olmadigini **mahkeme ciddiyetinde** aciklar. Yazilim calisir. Adalet calismaz. Muavin calisir, sen ayakta kalirsin.

## Misyon (abartili)

1. Bos koltugu tespit etmek.
2. Bos koltugun aslinda dolu oldugunu ispat etmek.
3. Pencere kenarinin bir hak degil, bir soylenti oldugunu zabta gecirmek.
4. "Biraz kayar misiniz" cumlesini diplomatik nota seviyesine cikarmak.
5. Inis duraginda herkesin ayni anda kalkmasini ulusal kriz ilan etmek.

Kurum adi: **TentiAS Sehir Ici Bosluk Istihbarat Dairesi**.
Kurucu kayyum: hesabin biyografisinde yazan kisi. Yani ben. Yani o. Karisik.

## Calistirma

Python 3 yeter. Dis bagimlilik yok, cunku dolmus da dis bagimlilik kabul etmez.

```bash
python protokol.py
python protokol.py --yolcu 14 --koltuk 11 --durak "Opera" --hava "cig"
python protokol.py --gizli-zabit
```

`--gizli-zabit` arsivdeki muhuru acar. Acma. Acarsan da parti adi arama, bulamazsin. Orada sadece bos koltuk teorisi vardir.

## Ornek karar

```
KARAR: Koltuk 7 bos gorunmektedir.
GEREKCE: Muavinin dirsegi, teyzenin poseti ve gorunmez bir "az sonra inecek" anayasasi.
HUKUM: Ayakta kal. Tutanak tutuldu. Ucret tam.
```
